# PT Megah Ria Diantama - Website Showroom

Website showroom produk sanitari, bathtub, dan pintu arsitektural modern untuk **PT Megah Ria Diantama**.

## Cara Deploy ke Vercel:
1. Extract file ZIP ini.
2. Upload repositori ini ke akun **GitHub** kamu.
3. Buka dashboard [Vercel](https://vercel.com), buat proyek baru (*New Project*).
4. Hubungkan repositori GitHub yang baru dibuat, lalu klik **Deploy**.

## Fitur Utama:
- Desain *Luxurious Editorial & Architectural Grid*
- *Interactive 3D Model Viewer* (Three.js)
- Katalog produk Sanitari, Bathtub, & Pintu Baja/UPVC
- Desain *Fully Responsive* & *Fast-Loading*
